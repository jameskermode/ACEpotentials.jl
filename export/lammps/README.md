# ACE IREE LAMMPS Plugin

LAMMPS ML-IAP unified interface for ACE models compiled to IREE VMFB format.

## Features

- **No Julia/Python dependency at runtime**: Uses IREE compiled model
- **Self-contained VMFB**: All embeddings computed inside the model
- **CPU and GPU support**: Via IREE backends (local-task, cuda, metal)
- **Complete physics**: Energy, forces, and virial computation

## Building

### Prerequisites

- LAMMPS with ML-IAP package
- IREE runtime libraries
- C++17 compiler

### Build Steps

```bash
# Set environment variables
export LAMMPS_SRC=/path/to/lammps/src
export IREE_DIR=/path/to/iree

# Build plugin
mkdir build && cd build
cmake ..
make

# Install
make install
```

### Using with LAMMPS

#### Option 1: As Shared Library Plugin

```bash
# Build as shared library
cmake -DBUILD_SHARED_LIBS=ON ..
make

# In LAMMPS input file:
pair_style mliap unified ace_iree
pair_coeff * * /path/to/libace_iree.so ace_model_cpu.vmfb ace_metadata.json Si O
```

#### Option 2: Built into LAMMPS

Copy the source files to LAMMPS src/ML-IAP and rebuild LAMMPS:

```bash
cp src/*.h src/*.cpp /path/to/lammps/src/ML-IAP/
cd /path/to/lammps/src
make yes-ml-iap
make mpi
```

## Usage in LAMMPS

### Example Input Script

```lammps
# Initialize
units metal
atom_style atomic
boundary p p p

# Read structure
read_data silicon.data

# Set up ACE potential
pair_style mliap unified ace_iree
pair_coeff * * ace_model_cpu.vmfb ace_metadata.json Si

# Run MD
velocity all create 300.0 12345
fix 1 all nvt temp 300 300 0.1
timestep 0.001
run 1000
```

### GPU Execution

For CUDA:
```lammps
pair_coeff * * ace_model_cuda.vmfb ace_metadata.json cuda Si
```

### Multiple Species

```lammps
# TiAl example
pair_coeff * * ace_model_cpu.vmfb ace_metadata.json Ti Al
```

The species order must match the order in the model's `species_Z` array.

## Model Files

The plugin requires:

1. **VMFB file** (`ace_model_cpu.vmfb` or `ace_model_cuda.vmfb`)
   - Compiled IREE module containing the ACE model
   - Generated by Julia export: `export_to_iree(compiled, output_dir)`

2. **Metadata file** (`ace_metadata.json`)
   - Contains model configuration: shapes, cutoff, species
   - Optional but recommended

3. **Constants file** (`ace_constants.npz`)
   - Contains model parameters (for validation only, not used at runtime)

## Generating Models

In Julia:
```julia
using ACEExport

# Load fitted ACE model
calc = load_ace_potential("my_model.json")

# Compile for deployment
compiled = compile_model(calc)

# Export to IREE format
export_to_iree(compiled, "export_dir/"; backends=[:cpu, :cuda])
```

## Technical Details

### Model Interface

The compiled model takes:
- `edge_rij`: `[max_edges, 3]` float32 - displacement vectors
- `atomic_numbers`: `[max_atoms]` int64 - atomic numbers (0 = padding)
- `edge_i`: `[max_edges]` int64 - source atom indices
- `edge_j`: `[max_edges]` int64 - target atom indices
- `n_atoms`: int32 - actual number of atoms
- `n_edges`: int32 - actual number of edges

And returns:
- `energy`: float32 scalar
- `forces`: `[max_atoms, 3]` float32
- `virial`: `[3, 3]` float32

### Fixed Shapes

Models are compiled with fixed maximum shapes:
- `max_atoms = 4096` (configurable at compilation)
- `max_neigs = 50`
- `max_edges = 200000`

Smaller systems are padded; larger systems will error.

### Embeddings

All embeddings (Chebyshev radial basis, spherical harmonics) are computed
inside the IREE model. This plugin only needs to build the edge list.

## Troubleshooting

### "Too many atoms/edges"

Recompile the model with larger shapes:
```julia
shapes = ACEExport.CompiledShapes(max_atoms=8192, max_edges=400000)
compiled = compile_model(calc; shapes=shapes)
```

### "Unknown species"

Ensure the element order in `pair_coeff` matches `species_Z` in metadata.

### IREE not found

Set `IREE_DIR` environment variable or install IREE:
```bash
pip install iree-runtime
```
